# Deployment Guide

## Production: Vercel
- Live: https://quick-free-cv-builder.vercel.app
- Project: `quick-free-cv-builder` (Vercel team `thadigitalgurus-projects`), connected to this GitHub repo.
- Every push to `main` deploys to production; other branches get preview URLs.
- Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

`vercel.json` carries the guarantees the app relies on. Keep it:
- **Content Security Policy** with `connect-src 'self'`: the browser refuses to send CV data to any other server.
- **Caching:** `index.html` is revalidated on every visit; hashed files in `/assets/` are cached for a year.
- **Routing:** every path except `/assets/` serves `index.html`, so a missing asset is a real 404 and a tab left open across a deploy reloads into the new version instead of breaking.

### Deploy by hand (if Git deploys are unavailable)
```bash
npm i -g vercel
vercel login
vercel link --project quick-free-cv-builder
vercel deploy --prod
```

### After a deploy
```bash
npm run test:e2e:live   # the browser suite against the live site
```
This runs the whole browser suite against production: headers, privacy (no outside requests), import, PDF export, undo and recovery.

## Alternative: Netlify
1. Import the GitHub repo.
2. Build command: `npm run build`. Publish directory: `dist`.
3. Keep `public/_headers` (same security and caching rules as `vercel.json`) and `public/_redirects` (SPA routes).

## Domain change
The live URL appears in `index.html` (canonical and `og:` tags), `public/robots.txt` and `public/sitemap.xml`. Update all three when adding a custom domain.

## Link preview image
`public/og-image.png` (1200×630) and `public/apple-touch-icon.png` (180×180) are generated by `node scripts/og-image.mjs`. Rerun it after changing the logo or tagline.

## Local verification
```bash
npm install
npm run build
npm run preview
```
